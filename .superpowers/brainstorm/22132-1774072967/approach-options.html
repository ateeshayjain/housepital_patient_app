How should we structure the Active Service Monitoring?

Three approaches — each handles the same information differently

A

Enhanced Home Screen

Expand the existing home screen with richer cards for each active service. Staff attendance, vitals, billing summary, and Health Manager contact all live on the home dashboard as expandable sections.

Pros

  • Everything in one place — no new navigation to learn
  • Builds on existing "Your Staff" and "Today's Vitals" sections
  • Fastest to build

Cons

  • Home screen gets very long and dense
  • Hard to show multiple active services (ICU + physio + equipment)
  • Remote family members have to scroll through everything to find what they care about
B

Dedicated "My Care" Tab

Add a new bottom tab — "My Care" — as the primary monitoring hub. Shows all active services as cards, each expandable into detail views. Home screen stays light (summary + quick actions), My Care goes deep.

Pros

  • Clean separation: Home = "what's happening now", My Care = "full picture"
  • Supports multiple active services naturally (list of service cards)
  • Remote family members go straight to My Care tab
  • Room to grow — add history, documents, reports later

Cons

  • New bottom tab — need to fit into existing tab bar
  • Some duplication with home screen (vitals shown in both places)
  • More screens to build
C

Service-Specific Detail Screens

Keep the home screen as-is, but make each active service card tappable → opens a full detail screen specific to that service type. ICU package gets a medical dashboard, Japa gets a simpler attendance view, equipment gets a rental tracker.

Pros

  • Each service type gets a tailored experience
  • ICU monitoring is very different from Japa monitoring — this respects that
  • Home screen stays clean

Cons

  • No unified view of "all my active services"
  • Most complex to build — multiple screen templates
  • Family member has to tap into each service separately

My recommendation: Option B — a dedicated "My Care" tab gives both patient and remote family a clear home base, scales to multiple services, and keeps the main home screen snappy. We can still use elements of C (service-specific detail views) when you tap into a service card from My Care.
