Data Flow — Staff ↔ Patient App

How medications sync between both apps via shared Supabase backend

Patient App WRITES:
  • Add/edit/delete medications
  • Update stock counts
  • Upload prescription photos
  • Set reminder preferences
Staff App WRITES:
  • Mark medication administered (time + who)
  • Record skipped dose + reason
  • Flag adverse reactions
  • Add PRN (as-needed) doses given
Shared Supabase Tables:
  • medications — master list (new table)
  • medication_logs — administration records
  • Real-time subscriptions for instant sync
  • Replaces JSONB in deployments table

Summary: Medications module has two views: (1) Daily schedule showing time-slotted meds with administered/pending/missed status, and (2) Full medication list with stock tracking, refill alerts, and add/edit capability. Both apps share the same Supabase tables in real-time.
